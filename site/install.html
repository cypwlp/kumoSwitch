First launch

第一次打開就上手

kumoSwitch 會自動掃描已安裝的 AI CLI。先看清楚目前設定，再決定要匯入、建立供應商，或直接切換。

  1. 選擇 Harness左側選 Codex、Claude Code、Gemini CLI 等工具。
  2. 匯入或新增供應商可讀取既有設定，也可手動填入 Base URL 與 API Key。
  3. 先看 diff 再套用只改供應商相關鍵位；寫入前自動建立時間戳備份。
  4. 重開該 CLI 終端多數工具只在新 session 讀取新設定。

FAQ

安裝常見問題

Windows 安裝版和可攜版差在哪？

安裝版會建立開始功能表項目、支援自動更新，適合日常使用。可攜版解壓後直接執行，不寫入安裝目錄，但仍會使用你的 AppData 保存 kumoSwitch 設定。

我的是 Apple Silicon 還是 Intel Mac？

Apple 晶片（M1、M2、M3、M4 或更新）選 macOS ARM；Intel 處理器選 macOS Intel。頁面會先嘗試自動偵測，你也可以手動切換。

Linux 要選 AppImage 還是 deb？

不想由套件管理器管理時選 AppImage；Debian／Ubuntu 系列要整合桌面選單時選 deb。AppImage 下載後需先加執行權限。

安裝後需要把原本的 cc-switch 關掉嗎？

不需要關，但若兩個工具同時接管同一份設定，後寫入的會覆蓋前一個。kumoSwitch 會在偵測到代理接管時提示；建議同一時間只讓一個工具負責寫入。

kumoSwitch 會上傳我的 API Key 嗎？

不會。kumoSwitch 沒有帳號、雲端同步或遙測。設定與備份保存在本機；Windows 使用 DPAPI 加密，macOS／Linux 使用 Keychain／Secret Service 保存主金鑰。

自動更新包含哪些平台？

Windows 安裝版、macOS Apple Silicon／Intel 與 Linux AppImage 使用簽章驗證的 latest.json 自動更新。Windows 可攜版與 Linux deb 需手動替換。
